모델 아키텍처 — 정체성 보존 적대적 공격

MAELS(arXiv:2402.03095) latent 분해를 frozen 사전학습 모델 위에 이식  ·  victim: ResNet-18 mixed_13  ·  generator: FLUX.2-klein

목표. victim classifier(ResNet)는 오분류시키되, 이미지의 정체성은 보존한다 — 즉 "개를 다른 클래스로 오인시키되, 사람 눈(과 CLIP)에는 여전히 개로 보이게". 픽셀에 노이즈를 얹는 고전 UAP가 아니라, 생성모델의 semantic 편집 축을 따라 걷는(walk) 방식으로 이걸 달성한다.

1. 한눈에 — 무엇이 frozen이고 무엇을 학습하나

MAELS는 z를 z1/z2/z3로 나누고 네 네트워크(E·G·Q·D)를 InfoGAN으로 함께 학습한다. 우리 세팅에서는 이 넷이 전부 이미 존재하는 frozen 사전학습 모델로 대체되고, 학습 대상은 z3(연속 semantic 축) 토큰 하나로 줄어든다.

3. 컴포넌트 설명

z1 = 입력 이미지 (토큰이 아니다)

MAELS의 z1은 E(z1|x) — 이미지마다 다른 per-image 정체성 코드다. FLUX는 image-editing 모델이라 입력 이미지 자체가 이미 이 역할을 한다. 그래서 정체성을 담는 별도 토큰이 필요 없다. 정체성 보존이 자연스럽게 t의 함수가 된다: 낮은 t = 이미지 지배(정체성↑), 높은 t = z3 지배(정체성↓).

z2 = 클래스 텍스트

"a photo of {class_label}"가 discrete 라벨 코드. untargeted 공격에서 z2는 정답에 고정된 채, victim을 그 정답에서 밀어낸다.

z3 = 학습되는 유일한 것

learnable textual-inversion token <v1>…<vN>을 z3_base + t·direction으로 파라미터화한다. direction만 gradient로 학습되고, t는 주입 강도를 조절하는 스칼라 다이얼(0=편집 없음, 1=최대).

Q = CLIP (frozen, victim과 독립)

왜 CLIP인가 — 학습해서가 아니라 "victim과 독립"이라서. 공격의 본질은 "F(ResNet)는 틀리는데 Q는 맞는" 간극을 찾는 것이다. 이 간극은 F와 Q가 충분히 다를 때만 존재한다. CLIP은 아키텍처·학습데이터·feature가 ResNet과 전혀 달라서, ResNet을 속인 이미지도 CLIP은 정답으로 읽을 수 있다. (만약 Q를 victim과 비슷하게 학습하면 Q≈F가 되어 간극이 사라지고 보존 성공률이 0이 된다 — 그래서 CLIP frozen을 쓴다.)

4. 손실 함수

각 강도 t에서 생성한 xSO(t)에 대해 두 항을 계산한다:

항수식의미
공격relu(z_true − max z_other)victim margin hinge. 이미 뒤집힌 샘플은 loss 0 → 최소 변화로 딱 경계까지만.
보존1 − CLIP_prob(true class)CLIP이 여전히 정답을 읽도록. 픽셀(SSIM)이 아니라 의미로 정체성 감시 → 포즈·시점 변화 허용.
 
L(t) = relu( z_true(t) − max z_other(t) )  +  w · ( 1 − CLIP_prob(x^SO(t), true) )
         └─────── 공격 (victim 속이기) ──────┘      └──── 보존 (CLIP 정체성 감시) ────┘

여러 강도 t에서 이 loss를 구해 낮은 t일수록 큰 가중치로 합산한다 — "약한 편집으로도 성공하면 더 보상"해서 필요 이상으로 밀어붙이는 붕괴를 억제한다.

공격 항은 두 후보가 있다. 위 margin hinge는 우리 현재 선택이고, MAELS 논문은 포화형 CE를 쓴다. 어느 쪽이 정체성 보존에 유리한지는 §7 비교 실험 계획에서 실측으로 가른다.

5. Strength walk — 가장 이른 정당한 crossing을 채택

MAELS가 z3를 작은 스텝으로 walk하며 victim이 처음 틀리는 지점을 고르는 것을 그대로 따른다. 평가 시 t를 0→1로 훑으며, victim이 틀림 AND CLIP은 여전히 정답을 만족하는 가장 작은 t를 채택한다.

t 낮음 — 아직 victim 못 속임 최초 성공 + 정체성 유지 → 채택 더 밀면 붕괴 (버림)

이 "최소 강도 채택"이 핵심이다 — 끝까지(t=1) 밀면 대부분 붕괴하지만, 그 이전 어딘가에서 멈추면 정체성이 보존된 진짜 편집이 나온다.

6. 왜 이 설계인가 — 핵심 통찰

  1. 4-network InfoGAN → frozen 3-model + 학습 z3. G를 새로 학습하지 않으니 E·G·Q·D가 전부 사전학습 모델로 대체되고, 학습은 z3 direction 하나로 축소된다.
  2. 정체성은 픽셀이 아니라 의미로 지킨다. LPIPS/SSIM 같은 픽셀 제약은 나쁜 overlay뿐 아니라 좋은 semantic 편집(포즈·시점)까지 막는다. CLIP oracle은 "큰 변화라도 정답으로 읽히면 OK".
  3. CLIP의 힘은 victim과의 독립성에서 나온다. 같은 계열(DINO 등) guard는 victim과 함께 속아서 실패했다. CLIP은 독립적이라 간극을 만든다.
  4. walk로 최소 강도를 고른다. "가장 세게 속이기"가 아니라 "가장 약하게, 정체성 유지하며 속이기"를 목표로 삼아 붕괴를 피한다.
알려진 한계 (다음 과제). 실측(§9, SP-ASR 26.5%)에서 성공의 상당수가 여전히 붕괴(collapse)해 소수 클래스로 몰린다. 전이 분석 결과 이 쏠림은 대체로 붕괴한 것들이 몇 개 sink로 몰린 현상이었고, 진짜 보존 성공은 더 고루 퍼져 있었다. 따라서 다음 지렛대는 loss 형태나 targeted 전환이 아니라 collapse 자체를 줄이는 것(oracle 압력 강화, t=0 재구성 앵커, 성공 샘플 masking)이다.

7. 손실 함수 비교 실험 계획 — 우리 margin vs 논문 CE

현재 공격 항은 margin hinge지만, MAELS 논문(Eq.8)은 포화형 cross-entropy를 쓴다. 둘 다 untargeted지만 gradient 성질이 달라서, 어느 쪽이 정체성 보존에 유리한지 같은 조건에서 attack 항만 바꿔 실측으로 가른다.

논문:  L_atk(t) = −λ_h · log( 1 − e^(−CE(F(x^SO(t)), y)) )      # 뒤집혀도 정답확률 낮출 때까지

7.2 가설

  • 논문 CE는 경계를 넘어 더 밀어붙인다(뒤집힌 뒤에도 정답확률을 계속 낮춤) → raw ASR은 같거나 높지만 collapse가 더 많고 SP-ASR(보존)은 낮을 것.
  • 우리 hinge는 경계에서 멈춘다(최소 변화) → 보존에 유리 → SP-ASR ≥ 논문 CE일 것.
  • 단, 평가 walk가 최소 t를 고르므로 학습 loss의 "얼마나 넘어가나" 효과가 일부 상쇄될 수 있음 → 실제 차이는 예상보다 작을 수도 있다.
